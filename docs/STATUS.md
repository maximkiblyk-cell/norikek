# Статус — v0.6.0

Это разработческий этап, а не выполнение MASTER PROMPT и не production-релиз. В основе только предоставленный starter и сохранённые промежуточные сборки; полный прежний проект и Sidecar не предоставлены.

Общий API SERVICE_TOKEN отключён. Доверенный polling-процесс бота с доступом к общей базе выпускает краткоживущие пользовательские сессии; API привязывает запросы к субъекту и проверяет роль. Владелец из конфигурации управляет назначением админов; блокировка отзывает сессии и запрещает device API. Компрометация самого бота, токена Bot API, БД, хоста или настройки владельца остаётся компрометацией доверенной стороны; внешняя инфраструктура и security-аудит не завершены.

Доступны ограниченные админские операции с пользователями, лицензиями, устройствами, тарифами, обращениями; нет полноценной пагинации, поиска, полного управления жизненным циклом и живой проверки Telegram. Тарифы фиксируются в новых лицензиях: срок, платформа и лимит устройств; ручные и старые grants не связаны с тарифом. Реальной покупки и подписочного биллинга нет.

Миграция SQLite известных схем v0.4/v0.5 работает на копии и протестирована с исходными историческими сборками и сохранёнными строками. Версионированная PostgreSQL v0.5 проверена на тестовой БД; автоматического переноса неверсированной PostgreSQL нет. На Windows и Docker проект не запускался, реальный токен Telegram не предоставлен. Игры отключены; разрешённый SDK и тестовые среды отсутствуют. Сведения о тестах и полной матрице — в соседних файлах.
