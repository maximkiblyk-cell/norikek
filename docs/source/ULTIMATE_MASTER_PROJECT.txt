# 01. 🖤 СТРУКТУРА ЭКОСИСТЕМЫ

NØRI состоит ровно из трёх основных технических компонентов.

## 1. 🤖 Telegram Bot

Полноценный Telegram-бот.

Это основной интерфейс взаимодействия пользователя с сервисом вне игры.

Всё управление осуществляется через стандартный Telegram:

- Вложенные меню.

- Лицензии.
- Настройки.

**Telegram Mini App, Web App и браузерный личный кабинет НЕ НУЖНЫ.**

Не предлагать их в качестве обязательной части проекта.

## 2. 🎮 Game Plugin

Игровой плагин, который устанавливается непосредственно в поддерживаемую игру.

Он открывает собственный внутриигровой интерфейс.

Пользователь не должен запускать отдельную программу для управления плагином.

Платформы:

- Hassle RP 2.0.
- Radmir CRMP.

Для каждой игры необходим отдельный адаптер с учётом её реального технического устройства.

## 3. ⚙️ Backend API

Серверная часть, которая связывает Telegram и игровой плагин.

Отвечает за:

- Пользователей.
- Устройства.
- Pairing.
- Лицензии.
- Подписки.
- Игровые события.
- Очередь уведомлений.
- Telegram Delivery.
- Настройки.
- Поддержку.
- Административные операции.
- Обновления.
- Безопасность.

Backend не должен зависеть от визуального интерфейса клиента.

1. Пользователь скачивает игровой плагин.
2. Устанавливает его в разрешённую директорию игры.
3. Запускает игру.
4. Открывает меню NØRI.
5. Выбирает Telegram.
6. Получает одноразовый код.
7. Открывает Telegram-бота.
8. Подтверждает подключение.
9. Backend связывает устройство с аккаунтом.
10. Плагин начинает передавать поддерживаемые игровые события.
11. Telegram доставляет уведомления.

Обратное направление:

Telegram → Backend → Проверка команды → Игровая очередь → Game Plugin → Подтверждение.

Необходимо реализовать:

- Pairing.
- Авторизацию устройства.
- Device Secret.
- Дедупликацию.
- Повторную доставку.

- Изоляцию пользователей.
- Проверку лицензии.
