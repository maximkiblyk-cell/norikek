## Блокеры и необходимые входы

1. Указать существующий репозиторий и ветку с исходниками именно v0.8.3 и предоставить разрешённый способ запустить GitHub Actions либо передать логи запуска workflow от владельца. Использовать изолированный Windows runner с правами на создание/удаление временного профиля. Не копировать в репозиторий секреты или production-данные.
2. Предоставить или самостоятельно использовать отдельный test Bot API token, тестовый Telegram-аккаунт, отдельную тестовую БД и защищённый HTTPS между host и API. Production токен не подходит.
3. Предоставить полноценный Docker host c доступом к daemon, достаточным UID/GID mapping и отдельным project name/volume; использовать только тестовую БД и конфигурацию.
4. После фактических запусков сохранить логи без токенов, ключей, pairing code, credentials и паролей; указать коммит, run ID, время, ОС, команды, ожидаемое и фактическое поведение. Без этих доказательств готовность внешних интеграций не подтверждена.

Игровые адаптеры и команды остаются выключены. Не применять эти инструкции к production. Предыдущая история и результаты сохранены в `V083_REPORT.md`.
