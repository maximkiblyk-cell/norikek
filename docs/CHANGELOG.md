## v0.8.3 — частичная стабилизация

Reconnect с backoff/jitter и отменой, fail-closed проверка curl options, сборка с явными зависимостями static curl, PostgreSQL pool pre-ping и новые тесты. Windows/DPAPI, реальный Telegram и Docker-контейнеры остаются непроверенными. См. `V083_REPORT.md`.

# Изменения


## 0.6.0 — пользовательские сессии, роли и тарифы

- Общий сервисный bearer отключён, добавлены краткоживущие сессии, роли user/admin/owner и привязка actor ID.
- Добавлено администрирование пользователей, устройств и тарифов; при блокировке отзываются сессии.
- Выдача по тарифу фиксирует срок, платформу и лимит устройств; платежи не имитируются.
- Добавлена миграция копий известных SQLite v0.4/v0.5 и новые интеграционные тесты.
- Реальный Telegram, Windows, Docker и игровые SDK не проверены. Production не заявлен.

## 0.5.0 — экспериментальные устройства и PostgreSQL

- Добавлены тестовые одноразовая привязка устройства, серверный лимит, device token, проверка лицензии и отзыв; по умолчанию выключено.
- Добавлены тарифы, контракт платёжного провайдера без успешной оплаты, Telegram admin-меню и очищенный журнал ошибок worker.
- Добавлены отдельные выключенные игровые адаптеры и типы контрактов событий/команд без имитации игры.
- Добавлены Alembic для новых баз, PostgreSQL, Dockerfile/Compose, конкурентные и многопроцессные тесты PostgreSQL.
- MASTER PROMPT остаётся незавершённым; реальные Telegram, платежи, игры, Docker и Windows не проверены.

## 0.4.0 — support и очередь уведомлений

- Добавлены переписка поддержки, категории, просмотр, ответы и закрытие в API и боте; ответы администратора записываются в журнал.
- Добавлены идентификаторы запросов для безопасных повторов создания обращения и ответов.
- Добавлены очередь уведомлений на ответы поддержки и отдельный worker Telegram с retry, lease и восстановлением. Настройки системных уведомлений работают по opt-in; возможны дубли при сбоях.
- Добавлены локальные тесты; реальная доставка Telegram и production окружение не проверены.

## 0.3.0 — тестовое лицензирование

- Добавлены персональные тестовые ключи, хеширование, активация с сохранением срока, продление с идентификатором запроса и отзыв; ведётся минимальный журнал успешных действий.
- Добавлены пользовательские и административные сценарии бота с подтверждением операций. Платежи и проверка игрового устройства не подключены.
- Добавлены тесты и smoke-check локального backend; реальный Telegram и production-окружение не тестировались.

## 0.2.0 — локальный starter

- Исправлен вызов отключённых игровых адаптеров.
- Добавлены локальная защита API сервисным токеном, сохранение пользовательских настроек и текстовых тестовых обращений.
- Бот обращается к API для регистрации, аккаунта, настроек и обращений; незавершённые функции обозначены явно.
- Небезопасные маршруты-примитивы pairing отключены до полноценного протокола; старая модель сохранена.
- Добавлены тесты, инструкции запуска и честный отчёт о проверках.

Это не релиз коммерческого продукта. Реальные игровые события и функции оплаты не добавлены.
